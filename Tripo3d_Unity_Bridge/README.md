# Tripo3D Unity Bridge

WebSocket-based Unity Editor plugin for receiving and importing 3D models directly from the Tripo3D web frontend.

**🇺🇸 English**

## Installation

Install the plugin into your Unity project (Unity 2021.3 or later):

1. Open **Window > Package Manager**.
2. Click **+** → **Add package from disk...**.
3. Select the `package.json` inside the extracted `Tripo3d_Unity_Bridge` folder.

After importing, open **Tools > Tripo3D Bridge** and click **Start Server** to begin receiving models.

For setup guides and workflow tutorials across Tripo DCC Bridge plugins, visit the **[Tripo DCC Bridge Guide Hub](https://www.tripo3d.ai/blog/tripo-dcc-bridge-guide-hub)**.
